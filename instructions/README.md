# Первая тестовая задача

## Цель

Проверить, что агент умеет читать инструкцию и возвращать понятный отчёт.

## Что нужно сделать

1. Прочитать эту инструкцию.
2. Ничего не изменять на компьютере.
3. Подготовить короткий ответ:
   - инструкция прочитана;
   - задача понятна;
   - действий пока не выполнено.

## Ограничения

- Не удалять файлы.
- Не запускать неизвестные команды.
- Не подключаться к аккаунтам.
- Не менять настройки компьютера.

## Формат ответа

Статус: готово

Инструкция:
first_task.md

Выполнено:
Инструкция прочитана, действий не выполнено.

Ошибки:
Нет.
