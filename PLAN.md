# План проекта

Мы создаём систему из нескольких модулей.

## Идея

- Perplexity используется как мозг для анализа и написания инструкций.
- ИИ-агент выполняет действия на компьютере.
- GitHub хранит код, инструкции, ошибки и отчёты.
- Android-эмулятор используется для запуска приложений.
- Скриншоты создаются только при необходимости.

## Модули

1. Рабочее пространство GitHub.
2. Инструкции для агента.
3. Выполнение команд и кода.
4. Сбор ошибок и отчётов.
5. Управление Android-эмулятором.
6. Передача результатов для анализа.

## Текущий этап

Создание рабочего пространства.
